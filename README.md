# 💰 CobraFácil

**Gestão de Cobranças para Pequenas Empresas**

Envie cobranças automáticas via WhatsApp, importe planilhas de devedores, gere documentos de negativação e controle pagamentos via Pix.

---

## Como rodar localmente

```bash
npm install
npm run dev
```

Acesse: http://localhost:5173

## Como fazer o build para produção

```bash
npm run build
```

## Tecnologias

- React 18
- Vite 5
- Deploy: Vercel
